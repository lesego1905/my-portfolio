# Lesego Khaola — Personal Portfolio

A polished, editorial-style personal portfolio website for Lesego Khaola, an Educator Assistant and Community Volunteer based in Westonaria, South Africa. The site presents her profile, skills, qualifications, experience, volunteering, projects, and contact details in a warm, professional layout.

## Live site

**[https://my-showcase-space-994.lovable.app](https://my-showcase-space-994.lovable.app)**

## Pages

- **Home** — Hero with portrait, headline, profile summary, and CV download.
- **About** — Full profile statement and quick facts (location, languages, availability).
- **Skills** — Eight core strengths with short descriptions.
- **Qualifications** — Education history and subjects.
- **Experience** — Educator Assistant role at Ipeleng Primary School.
- **Volunteering** — Community outreach, church fundraising, homework supervision, cleaning, and gym instruction.
- **Projects** — Community and school initiatives with images.
- **Contact** — Email, phone numbers, location, and references.

## Tech stack

- [TanStack Start](https://tanstack.com/start) — full-stack React framework
- [React 19](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS v4](https://tailwindcss.com) — utility-first styling
- [shadcn/ui](https://ui.shadcn.com) — accessible UI primitives
- [Vite](https://vitejs.dev) — build tooling

## Design

The visual direction is warm and editorial:

- Cream paper background (`#faf9f6`)
- Serif display headings (Playfair Display)
- Clean sans-serif body text (Inter)
- Terracotta accent color
- Thin rule lines and subtle fade-up motion
